🎮 Hangman game project

Domain: Python Programming Internship at CodeAlpha

➤ This project consists of a hangman game where the player guesses a word one letter at a time. 

📝 Breakdown: 
- It contains a list of words where one gets randomly chosen when the game starts. 
- The user should enter one character, otherwise the guess doesn't count. 
- Inside the game while loop, enumerate is used to keep track of the index of the character that is supposed to be replaced, when the user gets the input correct. 

🛠️ Key concepts used: random, while loop, if-else statements, strings, lists, enumerate
