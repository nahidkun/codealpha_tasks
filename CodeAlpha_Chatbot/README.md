🤖 Chatbot project

Domain: Python Programming Internship at CodeAlpha

➤ This project consists of a chatbot that replies to any question you have for it. 

📝 Breakdown: 
- The code connects to the AI client which belongs to google Ai.
- For the application to keep going, it uses a while loop that goes on forever. It only stops when the user types 'exit'.
- As the applications runs, the AI client generates answers based on the user's input.
